## Image Optimization Tips

### Online Tools
- **TinyPNG** (https://tinypng.com) - Compress without quality loss
- **ImageOptim** - Batch optimization
- **Squoosh** (https://squoosh.app) - Google's web compression tool

### Command Line (ImageMagick)
```bash
convert input.png -quality 85 -resize 1200x1400 output.jpg
```

### Best Practices
1. Use actual game cover art when possible
2. Maintain consistent image style
3. Ensure text is readable
4. Optimize file size (target: 200-300KB)
5. Test on mobile to ensure clarity

## Troubleshooting

### Images Not Showing
1. Check filename spelling (must match exactly)
2. Verify file is in `assets/images/games/` folder
3. Ensure file format is JPG or PNG
4. Clear browser cache (Ctrl+Shift+Delete)
5. Reload page

### Image Quality Issues
1. Ensure minimum 1200px width
2. Optimize file size (150-400KB)
3. Use high-quality source images
4. Avoid heavy compression

### File Size Too Large
Use TinyPNG or ImageMagick to compress before uploading.
